Total Visual Overhaul» (Копировать и вставить)

    Задача: Проведи системный визуальный апгрейд всех типов объектов на в игре. Сейчас они выглядят как базовые примитивы. Нам нужно превратить их в AAA-ассеты с сохранением высокой производительности.

    Главный принцип: Мы создаем один эталонный префаб (мастер-объект) для каждого типа, настраиваем для него идеальный PBR-материал, а затем используем InstancedMesh (или <Instances /> из drei), чтобы размножить его. В мелочах прячется великое: каждый объект должен иметь характерные черты своего материала.

    Шаг 1. Базовые природные объекты (Камни, Мох, Трава, Ветки):

        Камни: Сплюснутая геометрия с шумом. MeshStandardMaterial, roughness 0.8-0.9, Normal Map, vertexColors (от серого к темно-синему).

        Мох: Слои с альфа-текстурами (мягкие края). roughness 1.0, Normal Map, разные оттенки зелёного/бирюзового.

        Трава: Изогнутые плоскости с текстурой листа. InstancedMesh. Кончики с легким emissive для магии.

        Ветки: Изогнутые цилиндры, текстура коры, roughness 0.7. Рандомизация положения.

    Шаг 2. Архитектура и окружение (Постройки, стены, полы):

        Материалы: Для камня/бетона используй roughnessMap (грязь, следы времени). Для дерева — направление волокон (Anisotropy) и Normal Map. Для стекла и окон — transmission (прозрачность) и clearcoat (блики).

        Детализация: Добавь микрорельеф (трещины, сколы) через displacementMap. Если это кирпич — проработай швы и неровности кладки.

    Шаг 3. Люди и гуманоидные персонажи:

        Кожа: MeshPhysicalMaterial с обязательным SSS (Subsurface Scattering) — параметры transmission (0.1-0.2), thickness, sheen. Кожа должна пропускать свет (эффект живого тела).

        Волосы: Используй Alpha Cards (плоскости с текстурой волос), настрой Anisotropy для бликов.

        Одежда: Проработай ткань (ткацкий рисунок) через Normal Map. Для кожи (куртки, ремни) — clearcoat и roughnessMap (потертости).

    Шаг 4. Техника, механизмы и транспорт:

        Металл: metalness 1.0, roughness 0.2-0.4. Используй карты Anisotropy (для шлифованного металла) и Clearcoat (для лакированных поверхностей).

        Ржавчина и износ: Смешай базовый металл с текстурой коррозии через roughnessMap и Normal Map (чтобы ржавчина выглядела объемной).

        Пластик и стекло: Для пластика — матовость (roughness 0.5). Для стекол/фар — transmission и thickness.

    Шаг 5. Предметы быта и интерьер (Мебель, посуда, утварь):

        Керамика: clearcoat для глазури, roughness для глины.

        Ткани (скатерти, шторы): Двусторонний рендеринг, sheen для бархата, Normal Map для складок.

        Бумага и книги: Легкая прозрачность (transmission), шероховатость для старых страниц.

        Жидкости: MeshPhysicalMaterial с transmission, ior (коэффициент преломления) и thickness.

    Шаг 6. Флора и Фауна (Животные, птицы, насекомые, растения):

        Птицы: Видимые перья (Alpha Cards / плоскости). sheen для перелива оперения.

        Звери: Шерсть (Shell Texturing или слои полупрозрачных текстур). Normal Map для густоты.

        Рыбы/Насекомые: Чешуя и хитин. clearcoat, roughnessMap для влажного блеска.

        Растения: Стволы, стебли, прожилки, цветы. transmission для тонких лепестков.

    Шаг 7. Спецэффекты и Светящиеся объекты:

        Замени стандартные порталы на «светящиеся капли росы» или «биолюминесцентные грибы» (MeshPhysicalMaterial с transmission и внутренним emissive).

        Настрой pointLight и Bloom.

    Шаг 8. Оптимизация и Инстансинг (Критически важно):

        Напиши оптимизированный код компонентов (например, <RockField />, <Architecture />, <Props />).

        Для всех повторяющихся объектов (трава, камни, кирпичи, листья) используй InstancedMesh.

        Настрой matrices для инстансов так, чтобы они не выглядели как клоны: рандомизируй поворот, масштаб и легкую вариацию цвета.

        Используй LOD (Level of Detail) для сложных моделей: если объект далеко — показывай упрощенную версию.

    Вывод: Покажи архитектуру кода, где каждый тип объектов (Природа, Архитектура, Персонажи, Техника, Предметы) вынесен в отдельный компонент с правильными PBR-материалами и оптимизированным рендерингом.
